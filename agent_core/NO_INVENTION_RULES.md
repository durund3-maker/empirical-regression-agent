# No-Invention Rules

The agent must never invent empirical content, regardless of how plausible it seems.

## Prohibited Inventions

The agent must not invent:

- Data sources.
- File provenance.
- Variable names.
- Variable definitions.
- Variable formulas.
- Sample restrictions.
- Merge keys or matching rules.
- Winsorization, trimming, or outlier rules.
- Coefficients.
- Standard errors.
- P-values.
- Significance stars.
- Sample sizes.
- Table rows, columns, or notes.
- Figure patterns.
- Robustness outcomes.
- Heterogeneity differences.
- Mechanism interpretations.
- Literature support.
- Causal conclusions.
- Audit pass status.
- Reproduction success.

## Specific Prohibitions

- Do not change model specifications to obtain significance.
- Do not replace missing results with placeholders that look like results.
- Do not infer controls, fixed effects, or clustering from memory.
- Do not convert heterogeneity into mechanism evidence.
- Do not convert author expectations into verified evidence.
- Do not rewrite unsupported empirical conclusions as if they were audited facts.

## Handling Missing Information

If information is missing, the agent may only:

- Mark the field as missing.
- Mark the field as `needs_author_input`.
- Ask for author confirmation.
- Create a schema placeholder without empirical content.
- Write executable code that derives the item from documented data and approved rules.
- Record the missing item as a P0, P1, or P2 risk.

## Permitted Inference

The agent may infer file relationships only when directly supported by paths, naming conventions, logs, manifests, or explicit author notes. Every such inference must be labeled `agent inference` and audited before it is used as verified evidence.

## Result Language

Allowed language:

- "The table was generated by the listed do file and log."
- "The coefficient is present in the exported Stata table."
- "This output is pending audit."
- "This is an author-approved specification."

Forbidden language without verified evidence:

- "The hypothesis is supported."
- "The mechanism is confirmed."
- "The effect is robust."
- "The insignificant result should be fixed by changing controls."
- "The sample rule is reasonable" when it has not been approved.
